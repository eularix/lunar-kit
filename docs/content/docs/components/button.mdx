## Theming

Button colors auto-adapt to the active theme (Lunar / iOS / Android / Native).
The `ActivityIndicator` color and text color come from the resolved theme tokens
via `useThemeTokens()`.

| Theme   | Primary color    | Behavior                             |
|---------|------------------|--------------------------------------|
| lunar   | brand            | default (web/tauri)                  |
| ios     | systemBlue       | Apple HIG palette                    |
| android | M3 purple #6750A4| Material 3 palette                   |
| native  | resolves at runtime | iOS on iOS, Android on Android, lunar on web |

Switch themes from the demo's theme selector or programmatically via `useThemeStore`.

## API

| Prop          | Type                                                    | Default   |
|---------------|---------------------------------------------------------|-----------|
| `variant`     | `'default' \| 'destructive' \| 'outline' \| 'secondary' \| 'ghost' \| 'link'` | `'default'` |
| `size`        | `'default' \| 'sm' \| 'lg' \| 'icon'`                     | `'default'` |
| `loading`     | `boolean`                                               | `false`   |
| `disabled`    | `boolean`                                               | `false`   |
| `leftIcon`    | `ReactNode`                                             | —         |
| `rightIcon`   | `ReactNode`                                             | —         |
| `className`   | `string`                                                | —         |
| `textClassName` | `string`                                              | —         |

Plus all props from React Native's `Pressable`.
