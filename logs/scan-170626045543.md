## Part 2 — Bug / vuln scan (first pass, 3 parallel reviewers)

> ⚠️ These are **reviewer findings pending verification** — triage each against the source before fixing. Several are "risk"-level (uncertain). Do NOT blind-apply.

### A. Security — CLI path traversal / injection (HIGHEST — verify first)
- `packages/cli/src/utils/routing.ts:17` — user `modulePath` split+spread into `path.join` without validation (`../../app` escapes intended dir).
- `packages/cli/src/commands/module.ts:25` — `modulePath` joined with `cwd()` unsanitized.
- `packages/cli/src/commands/add.ts:228` & `:155` — `file.path` from **registry JSON** used in `fs.copy`/`path.join` without validation → traversal if registry entry is malicious (supply-chain).
- `packages/cli/src/commands/install.ts:53` — package names from registry passed to `execFile` (array form mitigates, but validate names).
- `packages/create-lunar-kit/src/index.ts:131` — `projectName` (argv) may reach `execa` without re-validating the regex applied at L57.
- **Fix pattern:** resolve the target and assert it stays within the intended root (`path.resolve(base, p)` then check `startsWith(base + sep)`); whitelist `[\w-/]` for names; reject `..` segments.

### B. Core components — lifecycle/animation bugs (medium, verify)
- `input-otp.tsx:97`, `toast.tsx:60`, `tabs.tsx:137/169`, `dialog.tsx:175`, `accordion.tsx:259-270`, `switch.tsx:43`, `slider.tsx:38-45` — missing/incorrect `useEffect` deps or shared-value sync; stale closures; `toast` may dismiss wrong id on remount.
- `search-bar.tsx:33` — debounce timer (`timerRef: any`) never cleared on unmount → setState-after-unmount risk.
- `select.tsx:84/211` — options `Map` never cleared when items unmount → leak.
- `date-range-picker.tsx:132` & `calendar.tsx:183` — temp state not synced when controlled props change; range mode reads `value` instead of `startDate`.
- `radio.tsx:88` — toggle not guarded against async double-fire.

### C. Core non-UI logic (low-medium, verify)
- `index.ts:15` / `cli-utils.ts:18` — `new Function('return __dirname')` fails silently in RN/browser (returns '').
- `useThemeTokens.ts` — `useColorScheme()` undefined on web masked by silent 'light' default.
- toast/toolbar hooks — multi-selector zustand → re-render storms (use `useShallow`).
- template files (`api.ts`, `env.ts`, `useForm.ts`, `app-store.ts`) — `any` types, unencoded URL params, non-reactive `process.env` read at boot.

### D. Primitives (low-medium, verify)
- `adaptive-modal.tsx:144` — `onDismiss` not in effect deps (stale closure).
- `bottom-sheet/use-bottom-sheet.ts:170/186` — `handleClose` missing from gesture `useMemo` deps; double `dismissTranslateY.value` assignment.
- `bottom-sheet.tsx:145` — `panGesture` can be null but used unconditionally in `GestureDetector`.
- `portal.tsx:26` — no validation of `container` prop.

**Reviewer false positive noted:** `bottom-sheet.tsx:274` (footerHeightCtx null guard) — reviewer confirmed already correct.
